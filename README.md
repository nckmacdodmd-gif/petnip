# PETNIP
Petnip é uma plataforma digital projetada para facilitar e humanizar o processo de adoção e apoio a animais em situação de vulnerabilidade. 
Seu propósito é conectar, de forma prática e segura, ONGs e protetores a uma comunidade de usuários dispostos a ajudar.

Para cada animal em busca de um lar, existe um coração pronto para amar e, por meio do aplicativo, os usuários podem encontrar seu novo melhor amigo explorando perfis detalhados por localização, porte e idade, ou podem optar por transformar uma vida através do apadrinhamento, contribuindo com alimentos, vacinas e cuidados essenciais.
